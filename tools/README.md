# Инструменты

Данные и генераторы лежат прямо в репозитории, чтобы не потерялись.

- `data/verbs.json` — 196 глаголов со спряжением, переводом, фразами и подстановками
- `data/sets.json` — наборы слов по дням для взрослых и детей
- `data/themes.json` — модули тем: числа, дни, месяцы, время, знакомство, погода, прилагательные
- `data/plan.json` — раскладка модулей по 52 дням

Сборка страницы:

    python3 tools/build_reglas.py

Проверки:

    npm install
    node tools/tests/run.js
